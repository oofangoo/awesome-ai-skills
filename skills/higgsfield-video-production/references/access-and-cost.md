# Access and cost

Checked November 23, 2026; recheck current terms and the actual account before execution.

Higgsfield's [Unlimited help](https://higgsfield.ai/creator-hub/help-center/credits/what-are-unlimited-models-and-which-plans-include-them) limits Unlimited to manual human use on its website and prohibits automation. Its web entitlement does not transfer to MCP/CLI. Coverage depends on the specific model, tier, period and active account state.

For Unlimited, provide a manual prompt/reference/settings bundle; do not automate its form, submission or generation queue. For supported programmatic work, use the official connector/API and its actual quote, including any distinct tool-supported grant. Do not label that route Unlimited or assume a historical zero-credit balance applies. If current tools and documentation disagree, resolve the billing uncertainty before submission.

Manual control checklist: correct workspace; selected model and input mode; intended reference thumbnails/roles; prompt; duration; framing; resolution; audio; count; current generation mode and displayed effective cost. Ask for the resulting job or output after the human submits it. Do not promise that slower automated clicks make prohibited automation acceptable.

The [Terms of Use](https://higgsfield.ai/terms-of-use-agreement) include Developer Access rules. Follow the current supported interface and applicable account terms rather than reproducing hidden web requests.
